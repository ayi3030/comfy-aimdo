## 2. 我对照上游 `ze_api.h` 复核后修正的问题（本次关键贡献）

复核基准：`oneapi-src/level-zero` master `include/ze_api.h`（已下载逐字核对）。

1. **`ZE_STRUCTURE_TYPE_PHYSICAL_MEM_DESC` 取值错误（严重）**
   - 原实现：`#define ... 0x1D`（作者标注为「TODO 待实机核对」）。
   - 上游真值：**`0x20`**。
   - 影响：`zePhysicalMemCreate` 会按 `desc.stype` 做参数校验，`0x1D` 会被驱动以
     `ZE_RESULT_ERROR_INVALID_ENUMERATION/ARGUMENT` 拒绝 → **整个 VMM 卸载通路直接失效**。
   - 处置：更正为 `0x20u`，并在注释中写明依据。

2. **`ze_context_desc_t` 缺 `flags` 字段（ABI 越界读取）**
   - 原实现结构体仅 `{stype, pNext}`（16 字节）；上游真结构为 `{stype, pNext, flags}`（24 字节）。
   - 影响：`zeContextCreate` 会读取 `desc->flags`（偏移 16），属越界读取（UB）。
   - 处置：补齐 `uint32_t flags;`，并设 `stype = ZE_STRUCTURE_TYPE_CONTEXT_DESC(0x0D)`（规范值）。
     *注：设计文档曾记「context desc 全 0 即可」；对照规范与上游 llama.cpp 用法，置 `0x0D` 更稳妥。若实机驱动只接受 0，可回退此一处。*

3. **显存总量用真实查询替代 12GiB 占位值**
   - 原实现：`g_ze_dev_total[i] = XPU_FALLBACK_VRAM`（硬编码 12GiB，作者标注 TODO）。
   - 处置：新增 `zeDeviceGetMemoryProperties` 动态解析（可选符号，缺失则回退占位值），
     结构体 `ze_device_memory_properties_t` 字段/偏移按 `ze_api.h` 精确复刻。

4. **`reserve`/`free` 尺寸与 `map` 对齐不一致（审查项 R-a，已闭环）**
   - 原实现：`xpu_mem_address_reserve`/`_free` 用**原始 `size`**，而 `create/map/unmap/setaccess` 用 `xpu_align(size)`。
   - 隐患：仅当 `zeVirtualMemQueryPageSize` 返回 >2MiB 时，`map` 的映射范围会超出 `reserve` 的预留范围（尺寸不一致）。
   - 处置：`reserve`/`free` 一并改用 `xpu_align(size)`，与其余四个调用点统一。
     *实机 B580 页大小 64KiB，入参来自 `vrambuf_create` 的 2MiB 对齐（`CUDA_ALIGN_UP`），2MiB 是 64KiB 整数倍 ⇒ `xpu_align(size)==size`，本改动在 B580 上为恒等变换、**无行为变化**；init 另保留「>2MiB 页告警」防御。*

**其余函数签名**（`zeContextCreate`/`zePhysicalMemCreate`/`zeVirtualMemMap`/`zeVirtualMemSetAccessAttribute`
无 pNext/`zeVirtualMemQueryPageSize`/`zeMemGetAllocProperties` 等）**已逐一核对，与上游一致**。

5. **Python 层 `get_tensor_from_raw_ptr` 对 XPU 误用 CUDA 张量接口（审查项 R-g，已闭环）**
   - 原实现无条件用 CUDA 专有的 `__cuda_array_interface__` 包装裸指针；注释虽称「XPU 不走此路径」，
     但函数本身对任何 device 都会执行该 CUDA 协议，XPU 下误用会得到难以定位的错误结果。
   - 处置：新增守卫 —— 仅当设备为 `cuda`（torch 中 HIP 亦报 `cuda`）或未指定时放行，否则抛
     `NotImplementedError` 并给出明确指引。**对既有 CUDA/HIP 调用路径为恒等放行、无行为变化**。
     （已用 `py_compile` + AST 解析 + 多形态 device 静态核对通过；该函数当前仅被 `examples/example.py`
     与 CUDA 测试调用，均传 `cuda` 设备，不在 XPU 端到端热路径上。）
